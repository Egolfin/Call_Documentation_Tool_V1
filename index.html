QUICK GUIDE

How to use Call Documentation

  1. 01

    Select a response

    Work through each documentation field and select the response that best matches what happened during the call.

  2. 02

    Review “When to use”

    The guidance directly below each selection explains when that response should be used. Review it whenever you're unsure which response best matches the call.

  3. 03

    Complete every field

    Continue until the completion indicator shows that all required fields are complete.

  4. 04

    Review your completed note

    Your selections automatically appear in the Live Preview panel. Review the completed documentation before copying it.

  5. 05

    Copy the note

    Select Copy completed note when all fields are complete. You can also use Ctrl + Enter on Windows or ⌘ + Enter on Mac.

  6. 06

    Start the next call

    After the documentation has been copied, select New call to clear the current documentation and begin again.

Quick tip

Your draft is saved in the current browser tab while you work, so you won't lose your selections accidentally.
